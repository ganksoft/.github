Ganksoft is a small studio founded around 1997. We build games, tools, and emulators for retro and modern video game consoles, and PC.
 
## 🎮 Games
 
- **[Hugger-Mugger](https://ganksoft.com/games/hugger-mugger/)** — Atari Lynx — Toss blocks into shifting formations and clear the matching patterns before time runs out.
- **[Grogger](https://ganksoft.com/games/grogger/)** — Atari Lynx — Sling bottles of grog to a motley group of thirsty patrons.
- **[Chomp!](https://ganksoft.com/games/chomp/)** — Xbox One · Windows — Avoid the red monster while eating your fill of stars!
- **[Head Banger](https://ganksoft.com/games/headbanger/)** — Xbox One · Windows — Bang your head to stardom in this rhythm-based music game.
- **[DC Tonic](https://ganksoft.com/games/dctonic/)** — Dreamcast — A compilation CD distributed at E3 2001.

## 🛠️ Apps & Tools
 
- **[Gearlynx Debugger](https://ganksoft.com/apps/gearlynx-debugger/)** ([repo](https://github.com/ganksoft/gearlynx-vscode)) — Cross-platform — VS Code extension for source-level debugging of Atari Lynx games built with cc65, powered by the Gearlynx emulator.
- **[Nanopad](https://ganksoft.com/apps/nanopad/)** ([repo](https://github.com/ganksoft/nanopad)) — Windows — A modern, fast Win32 text editor in the spirit of classic Notepad.
- **[IP Upload](https://ganksoft.com/apps/ipupload/)** ([repo](https://github.com/ganksoft/ipupload)) — Windows — A simple uploader for the Dreamcast IP Slave.

## 🕹️ Emulators
 
Old hardware running even older hardware.
 
- **[Sarien DC](https://ganksoft.com/games/sariendc/)** — Dreamcast — Play classic Sierra computer games on the Sega Dreamcast.
- **[NeoPocott DC](https://ganksoft.com/games/npdc/)** — Dreamcast — A NeoGeo Pocket Color emulator for the Dreamcast.
- **[DreamPac](https://ganksoft.com/games/dreampac/)** — Dreamcast — A Pacman emulator for your Sega Dreamcast.
- **[Annoid](https://ganksoft.com/games/annoid/)** — Windows — An Arkanoid emulator for your PC.
